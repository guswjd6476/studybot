# 공부 추천 봇 (텔레그램)

오늘 **꼭 해야 할 일정**을 보내면, 남는 시간(08:00~23:00)에 무엇을 어떻게 공부할지 짜 주는 텔레그램 봇입니다.
AI 없이 정해 둔 규칙으로 추천합니다.

## 쓰는 법 (텔레그램)
- 일정을 한 줄에 하나씩: `9-12 수업`, `14:00~16:00 알바`, `오후 7시부터 8시 약속` (없으면 `없음`)
  - 오전·오후 없이 쓴 1~6시는 오후로 읽음. 아침 일정은 `오전 6:30-11:30`, `아침 6-8`, `06:30-11:30` 처럼
- `/목표 수학 2026-12-10` 과목 등록 (시험일 생략 가능, `12/10`도 됨) · `/목표` 목록 · `/목표삭제 수학`
- `/추천` 일정 없이 하루 전체로 추천
- `/내일` 내일 계획 미리 짜기 (다음 줄부터 내일 일정, 내일 요일의 고정 일정이 자동으로 들어감)
- `/공부시간 4시간` 하루 공부 상한 (기본 4시간, 빈 시간을 앞에서부터 이만큼만 채움)
- `/고정 월수금 18-22 알바` 매주 반복 일정 등록 (요일: `월수금`, `월-금`, `평일`, `주말`, `매일`) → 그 요일 계획에 자동으로 들어감 · `/고정` 목록 · `/고정삭제 1`
- `/할일 수학 문제집 3장` 할 일 추가 (여러 줄 가능) · `/할일` 목록 · `/완료 1 3` 체크(다시 하면 풀림) · `/할일삭제 2` — 못 끝낸 건 다음 날로 넘어가고, 계획·아침 알림에 남은 할 일이 같이 나옴
- `/알림 07:30` 매일 아침 일정 묻기 (기본 07:30) · `/알림 끄기`
- `/기록 수학 50분` 공부한 시간 기록 (`1시간 30분`, `90`도 됨) · `/기록취소` 오늘 마지막 기록 지우기
- `/시작 수학` 공부 타이머 → `/끝` 하면 걸린 시간 자동 기록 (과목 생략 시 계획의 지금 과목, 5시간 넘으면 끄는 걸 잊은 걸로 보고 기록 안 함)
- `/오늘` · `/이번주` 과목별 공부 시간 (이번 주는 월요일부터), 오늘은 목표 달성률·🔥 연속 공부일도
- 오늘 계획을 짜면 공부 칸이 시작할 때 알림 · `/시간알림 끄기` / `/시간알림 켜기`
- `/모두` 단톡방에서 같이 쓰는 사람들의 오늘·이번 주 공부 시간, 과목·D-day 보기

## 같이 쓰기 (단톡방)
- 같이 공부할 사람과 단톡방에 봇을 초대하세요. 과목·기록·알림은 **사람마다 따로** 저장되고, 추천·기록 결과는 방에 올라와 서로 보입니다.
- 단톡방에서 `9-12 수업` 같은 일반 메시지를 봇이 받으려면 @BotFather → `/setprivacy` → 봇 선택 → **Disable** 해야 합니다 (바꾼 뒤 봇을 방에서 내보냈다가 다시 초대).
- 아침 알림은 `/start`나 `/알림`을 마지막으로 보낸 방으로 갑니다.

## 추천 규칙 (`src/plan.ts`)
- 일정 사이 30분 이상 빈 시간을 50분 공부 + 10분 쉬기로 나눔
- 과목은 돌아가며 배치, 시험이 7일 안이면 3배·30일 안이면 2배 자주
- 공부 방법: 시험 7일 안 → 기출·오답 / 오전 → 새 개념 / 40분 미만 → 짧은 복습 / 오후 → 문제 풀이 / 마지막 칸 → 백지 인출 복습

## 실행
1. 텔레그램 @BotFather 에서 봇을 만들고 토큰을 받습니다.
2. `.env` 파일을 만들고 `TELEGRAM_BOT_TOKEN=받은토큰` 한 줄을 넣습니다.
3. `npm install` → `npm run build` → `npm start` (Node 20.6 이상, 코드를 바꾸거나 `git pull` 한 뒤엔 다시 `npm run build`)
   - 공개 주소가 없으면 롱 폴링으로 돌아갑니다 (내 PC·항상 켜진 서버용)
4. **alwaysdata (추천 방법)**: 사이트가 아니라 **서비스**로 돌리세요. 서비스는 잠들지 않고, 꺼지면 자동으로 다시 켜지고, 디스크도 유지돼서 기록이 안 지워집니다. 이때는 폴링 그대로라 주소 설정이 필요 없어요
   - SSH로 `npm install` → `npm run build`, 프로젝트 폴더에 `.env` 만들기
   - 관리 화면 **Advanced → Services → Add**: Command `npm start`, Working directory 는 프로젝트 폴더 (예: `/home/계정/studybot`)
   - 코드를 바꾼 뒤엔 `npm run build` 하고 서비스를 다시 시작
   - 같은 봇을 사이트·SSH에서 또 띄우지 마세요 (둘이 겹치면 메시지를 서로 뺏어 감)
5. **잠드는 무료 서버** (Render 등, 또는 alwaysdata를 사이트로 돌릴 때): 공개 주소가 있으면 웹훅으로 돌리고 **봇이 5분마다 자기 주소를 불러** 깨어 있게 합니다
   - 주소는 알아서 찾습니다: Render·Koyeb·Railway·Fly.io. alwaysdata 사이트처럼 다른 곳이면 환경 변수 `WEBHOOK_URL=https://내앱주소` 를 넣으세요. 포트는 `PORT`(없으면 3000)
   - 로그에 `웹훅 https://...` 가 보이면 성공, `폴링` 이 보이면 주소를 못 찾은 것
   - ⚠️ 무료 서버는 다시 배포하거나 재시작하면 `data/store.json`이 지워지는 곳이 많습니다 (Render 무료가 그렇습니다). 기록을 오래 남기려면 디스크가 유지되는 곳을 쓰세요

- 테스트: `npm test` · 타입 검사: `npm run typecheck`
- 데이터는 `data/store.json` 한 파일에 저장됩니다 (봇은 한 곳에서만 띄우세요).
